### Нужен ли Docker

Docker не обязателен. Для разработки достаточно уже установленного PostgreSQL через Homebrew. Это самый короткий путь на этом Mac.

Docker пригодится, если хочется изолированную, легко пересоздаваемую БД и окружение, похожее на production. Не нужно одновременно держать PostgreSQL Homebrew и контейнер на одном порту `5432`.

Вариант A, использовать PostgreSQL из Homebrew:

```bash
brew services restart postgresql@15
pg_isready
createdb sa_hr_bot
psql -d sa_hr_bot -c 'select version();'
```

Если `pg_isready` снова не отвечает, проверить состояние и лог сервиса:

```bash
brew services list
brew services info postgresql@15
```

Вариант B, установить Docker Desktop через Homebrew:

```bash
brew install --cask docker
```

После установки нужно один раз открыть Docker Desktop и дождаться запуска engine. Затем проверить:

```bash
docker --version
docker compose version
docker info
```

Docker Desktop также можно скачать с официального сайта Docker. Установка через Homebrew удобнее тем, что приложение потом проще обновлять командой Homebrew. Для этого проекта отдельная ручная установка PostgreSQL с сайта не нужна.

### Минимальная подготовка локальной БД

После выбора Homebrew PostgreSQL или Docker PostgreSQL:

1. Создать пустую БД (locally сейчас используется `sahrbot`).
2. Указать корректный `DATABASE_URL` в `.env`.
3. Применить миграции командой `make migrate` (бот также применяет их при старте).
4. Импортировать `question_bank.csv` утилитой `cmd/import-questions`.
5. Сгенерировать хотя бы один одноразовый код утилитой `cmd/generate-codes`.
6. Только после исправления критичных проблем ниже запускать полноценное интервью в Telegram.

Полезные команды для будущей проверки, когда код будет готов:

```bash
go test ./...
go vet ./...
go build ./...
make migrate
go run ./cmd/import-questions -file question_bank.csv
go run ./cmd/generate-codes -n 1
go run ./cmd/bot
```

Последняя команда запускает long polling и начнёт обращаться к Telegram, OpenAI и БД. Не запускать её случайно с production-токеном.
